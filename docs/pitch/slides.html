역할 분리 · code counts, llm labels

숫자는 코드가 세고, LLM은 라벨만 붙임

LLM에게 "몇 건이야?"를 물으면 그럴듯한 숫자를 지어냅니다. 그래서 LLM은 문장 하나당 라벨과 인용문만 내고, 집계·중복 제거·순위는 전부 일반 코드가 합니다.

LLM 이 하는 일
  • 주제 이름 붙이기
  • 문장마다 라벨 (우회 / 이탈 / 반박…)
  • 라벨의 근거 인용문 1개
  • 몇 건인지 세기 · 순위 매기기
코드가 하는 일
  • 중복 제거 · 독립 관측 세기
  • 사다리 합계 · 반박 비율
  • 임계값으로 밴드 · 순위
  • 인용문 원문 대조, 없으면 폐기
